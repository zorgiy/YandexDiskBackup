# YandexDiskBackup

Русская программа на PowerShell 7 для резервного копирования **своего** Яндекс Диска в Windows.

**Режимы входа:** Автоматически — OAuth для списка файлов и загрузки через API, а при ошибке предлагает WebDAV; Только API — достаточно одного OAuth; Только WebDAV — достаточно логина и пароля приложения (список файлов через PROPFIND). Необязательный WebDAV запрашивается только при необходимости.

**Прогресс:** перед восстановлением программа сканирует все папки и рассчитывает общее количество файлов и их размер. На едином экране показываются общий процент по числу обработанных файлов, количество файлов, объём подтверждённых локальных файлов из общего размера, объём скачанного за текущий запуск, время работы и текущий метод API/WebDAV. Показатель «обработано» может достигнуть 100% даже при ошибках скачивания — для оценки полноты используйте «сохранено по размеру» и счётчик ошибок.

**Возможности:** рекурсивный обход облака, сохранение оригиналов через WebDAV, повторный запуск с пропуском уже скачанных файлов (проверка размеров), расшифровка типовых ошибок 503/500, журнал. Программа не удаляет файлы в облаке или на компьютере.

## Запуск одной командой

Откройте **PowerShell 7** и выполните:

```powershell
irm https://raw.githubusercontent.com/zorgiy/YandexDiskBackup/main/install.ps1 | iex
```

Скрипт установки попросит подтверждение загрузки и затем **отдельное подтверждение запуска**. Перед запуском лучше самостоятельно ознакомиться с кодом [install.ps1](install.ps1) и [YandexDiskBackup.ps1](YandexDiskBackup.ps1).

## Получение ключей

1. **Логин:** имя учётной записи Яндекса **без `@yandex.ru`**, например `ivan123`. Если ввести адрес целиком, программа автоматически возьмёт часть до `@`.
2. **WebDAV-пароль приложения:** https://id.yandex.ru/security/app-passwords — отдельный пароль для доступа к файлам.
3. **OAuth-токен:** https://oauth.yandex.ru/ — зарегистрировать OAuth-приложение с минимальным разрешением `disk:read`. Документация: https://yandex.ru/dev/id/doc/ru/tokens/debug-token.

Программа проверяет только необходимые для выбранного режима способы доступа. При ответе **HTTP 401** предлагает заново ввести логин и оба ключа (до трёх попыток). При ошибках авторизации ключи **не сохраняются**. Если ранее сохранены неверные ключи, их можно заменить в ходе повторного ввода или сбросить через пункт 3 меню.

При первом успешном запуске можно сохранить ключи в виде зашифрованного Windows CLIXML (для текущего пользователя Windows на текущем ПК). **Не публикуйте ключи в репозитории.**

По умолчанию резервные копии сохраняются в `Downloads\YandexDiskBackup` текущего пользователя Windows; можно указать существующую папку. Если у вас старая резервная копия в `YandexDisk\Original`, выберите подходящую папку для новой структуры и не удаляйте старую, пока не убедитесь, что всё сохранено.

**Важно:** ошибки HTTP 503 указывают на временную недоступность выдачи файла; они не доказывают его безвозвратную утрату. Интернет-соединение и доступность файлов могут влиять на результат.

**Ограничения:** приложение пока не протестировано на реальном Windows ПК в этой среде; первая версия — без автообновления и без скачивания превью. Проверка совпадения размеров не равнозначна проверке содержимого по хэшу. Скрипты размещаются открыто для проверки.
