# YandexDiskBackup

Русская программа на PowerShell для резервного копирования **своего** Яндекс Диска в Windows.

**Меню:** пункт `1` запускает/продолжает восстановление, пункт `3` отключает сохранённый аккаунт Яндекса (логин WebDAV, пароль приложения и OAuth-токен), а пункт `4` только меняет и сохраняет режим и возвращает в меню. Режим по умолчанию — автоматический.

**Режимы входа:** Автоматически — OAuth для списка файлов и загрузки через API, а при ошибке предлагает WebDAV; Только API — достаточно одного OAuth; Только WebDAV — достаточно логина и пароля приложения (список файлов через PROPFIND). Необязательный WebDAV запрашивается только при необходимости.

**Статистика методов:** во время работы и в итогах отдельно показываются количество и объём успешно скачанных файлов через API и через WebDAV за текущий запуск. В `_download-methods.tsv` записывается способ успешной загрузки для каждого нового файла. Уже существующим локальным файлам способ получения не приписывается. Старый журнал `_backup-status.tsv` сохраняется без изменений.

**Прогресс:** перед восстановлением программа сканирует все папки, рассчитывает общее количество файлов и размер, затем проверяет локальную резервную копию. Сразу отображаются количество и объём уже сохранённых файлов и сколько остаётся восстановить (по совпадению пути и размера, без проверки хэшей). На едином экране показываются общий процент по числу обработанных файлов, количество файлов, объём подтверждённых локальных файлов из общего размера, объём скачанного за текущий запуск, время работы и текущий метод API/WebDAV. Показатель «обработано» может достигнуть 100% даже при ошибках скачивания — для оценки полноты используйте «сохранено по размеру» и счётчик ошибок.

**Возможности:** рекурсивный обход облака, сохранение оригиналов через WebDAV, повторный запуск с пропуском уже скачанных файлов (проверка размеров), расшифровка типовых ошибок 503/500, журнал. Программа не удаляет файлы в облаке или на компьютере.

## Быстрый запуск через GitHub Pages

После включения GitHub Pages (ветка `main`, каталог `/ (root)`) откройте **PowerShell 7** и выполните:

```powershell
irm https://zorgiy.github.io/YandexDiskBackup/go.ps1 | iex
```

Короткая ссылка ведёт на [go.ps1](go.ps1), который получает актуальный [install.ps1](install.ps1), а тот скачивает и запускает [YandexDiskBackup.ps1](YandexDiskBackup.ps1). При каждом запуске используется новый параметр URL для обхода устаревшего CDN-кеша. Запросов подтверждения от установщика нет; подтверждения важных операций остаются внутри программы.

**Если GitHub Pages ещё не опубликован или возвращает HTTP 404**, используйте прямую команду:

```powershell
irm https://raw.githubusercontent.com/zorgiy/YandexDiskBackup/main/install.ps1 | iex
```

Проверить статус публикации можно в [настройках Pages](https://github.com/zorgiy/YandexDiskBackup/settings/pages). Команды с `iex` исполняют код из интернета — перед первым запуском ознакомьтесь с файлами [go.ps1](go.ps1), [install.ps1](install.ps1) и [YandexDiskBackup.ps1](YandexDiskBackup.ps1).

## Получение ключей

1. **Логин:** имя учётной записи Яндекса **без `@yandex.ru`**, например `ivan123`. Если ввести адрес целиком, программа автоматически возьмёт часть до `@`.
2. **WebDAV-пароль приложения:** https://id.yandex.ru/security/app-passwords — отдельный пароль для доступа к файлам.
3. **OAuth-токен:** https://oauth.yandex.ru/ — зарегистрировать OAuth-приложение с минимальным разрешением `disk:read`. Документация: https://yandex.ru/dev/id/doc/ru/tokens/debug-token.

Программа проверяет только необходимые для выбранного режима способы доступа. При **HTTP 401** программа предлагает заново ввести только ключи выбранного режима (до трёх попыток). Непроверенные новые ключи не сохраняются при ошибках авторизации. Если ранее сохранены неверные ключи, их можно заменить в ходе повторного ввода или сбросить через пункт 3 меню.

При первом успешном запуске можно сохранить ключи в виде зашифрованного Windows CLIXML (для текущего пользователя Windows на текущем ПК). **Не публикуйте ключи в репозитории.**

По умолчанию резервные копии сохраняются в `Downloads\YandexDiskBackup` текущего пользователя Windows; можно указать существующую папку. Если у вас старая резервная копия в `YandexDisk\Original`, выберите подходящую папку для новой структуры и не удаляйте старую, пока не убедитесь, что всё сохранено.

**Важно:** ошибки HTTP 503 указывают на временную недоступность выдачи файла; они не доказывают его безвозвратную утрату. Интернет-соединение и доступность файлов могут влиять на результат.

**Ограничения:** программа проверялась пользователем в Windows 11 и PowerShell 7.6.7 в режимах WebDAV и Auto, но полноценный автоматизированный набор тестов и все сетевые сценарии ещё не покрыты; отдельного автообновления и скачивания превью нет. Проверка совпадения размеров не равнозначна проверке содержимого по хэшу. Скрипты размещаются открыто для проверки.

## Смена аккаунта

В меню выберите `3 — Сменить аккаунт Яндекса (сбросить вход)` и подтвердите `y`. Это удаляет локально сохранённые логин, пароль WebDAV и OAuth-токен, но **не** удаляет фотографии и файлы резервной копии. При следующем подключении введите данные другого аккаунта. **Для каждого аккаунта выбирайте отдельную папку резервной копии**: программа считает файл уже сохранённым, если совпадает путь и размер, а это не гарантирует одинаковое содержимое файлов разных аккаунтов.
